# Excel Production Dashboard 📊

## Project Overview
This project presents an interactive Excel Production Dashboard designed to analyze manufacturing performance, production costs, product categories, and manager-wise task distribution.

The dashboard transforms raw production data into meaningful insights to support better business decision-making.

![Excel Production Dashboard](https://github.com/user-attachments/assets/3004265d-34e6-46a1-acd6-e3edd5b47d9a)

## Dataset Overview
- 120 production records
- Production dates
- Regions and managers
- Product categories
- Units produced
- Total production costs
- Employee gender and age groups

## Key Analysis
- Total production cost by product category
- Manager-wise task distribution
- Monthly and yearly production trends
- Average production cost per unit
- Product-wise production performance

## Excel Skills Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Excel Formulas
- Calculated Columns
- Data Visualization
- Dashboard Design

## Workbook Structure
| Sheet | Description |
|---|---|
| Dashboard | Main production dashboard |
| Production Dataset | Raw production data |
| Pivot 1 | Total cost by product type |
| Pivot 2 | Tasks by manager |
| Pivot 3 | Units produced over time |
| Pivot 4 | Average production cost per unit |

## Project Objective
To demonstrate practical Excel skills by converting raw production data into an interactive dashboard that highlights important operational metrics and trends.
